# 오늘의 플래너 — GitHub Pages 배포 파일

이 폴더에는 GitHub Pages에 올릴 수 있는 `index.html`과 배포 안내가 들어 있습니다. 사이트는 별도 빌드 없이 동작하는 정적 HTML/CSS/JavaScript 파일입니다.

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만듭니다. GitHub Free를 사용한다면 저장소 공개 범위를 **Public**으로 선택하세요.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상단에 업로드합니다. `index.html`이 저장소 루트에 있어야 합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 Source를 **Deploy from a branch**로 설정합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.
6. Pages 설정에 표시되는 공개 주소를 엽니다. 보통 `https://<GitHub 사용자명>.github.io/<저장소명>/` 형태입니다.

GitHub의 화면이나 계정 정책에 따라 메뉴 이름과 선택지는 달라질 수 있습니다. Pages 설정이 보이지 않으면 저장소 관리자 권한이 있는지 확인하세요.

## 공개 범위와 플래너 데이터

- 사이트에 접속한 사람은 각자 플래너를 사용할 수 있습니다.
- 일정, 카테고리, 테마, 음악 취향은 각 방문자의 브라우저 저장소에 저장되며 서로 공유되거나 서버로 동기화되지 않습니다. 브라우저 데이터 삭제 시 해당 브라우저의 기록도 사라질 수 있습니다.
- GitHub Free에서는 Pages 사용을 위해 저장소를 공개로 만들어야 하므로 사이트 코드도 누구나 볼 수 있습니다. 사이트 자체는 공개 웹페이지로 제공됩니다.
- 이 배포 폴더에는 플래너 사용자의 일정 데이터나 비밀 키를 넣지 않았습니다.

현재 ChatGPT Sites 주소는 유지되며, GitHub Pages에는 별도의 새 주소가 생깁니다.
